# Игровые рецензии — WPF + PostgreSQL

Десктопное приложение на C# (.NET 8, WPF) для вашей БД `video-game-reviews`.
Интерфейс повторяет структуру страницы https://tijoe.net/game-reviews/: тёмная тема, шапка с навигацией,
фильтр по жанрам, список игр с эмодзи-оценками 🔥 👍 🍺 😐 👎, лидерборд, профиль.

## Запуск

1. Развернуть БД (PostgreSQL):
   ```
   createdb game_reviews
   psql -d game_reviews -f work.sql      # схема, домены, триггеры
   psql -d game_reviews -f 6punkt.sql    # данные (включает CREATE EXTENSION pgcrypto)
   ```
2. Прописать подключение в `appsettings.json` (или в переменной окружения `GAMEREVIEWS_CONNECTION`).
3. Запустить (нужен Windows и .NET 8 SDK, например Visual Studio 2022):
   ```
   dotnet run
   ```

## Тестовые аккаунты (из 6punkt.sql, пароль у всех `Passw0rd!`)

| Роль | Логин |
|---|---|
| Администратор | `admin_01` |
| Критик | `critic_01` … `critic_10` |
| Пользователь | `user_001` … |

## Роли (пункт 9 задания)

- **Гость** — смотрит игры, жанры, рецензии, лидерборд.
- **Пользователь** — то же + регистрация/вход, профиль, история просмотренных рецензий (`review_views`).
- **Критик** — пишет, правит и удаляет свои рецензии с оценкой 1–10 (`reviews` + `ratings`, одна транзакция);
  средний рейтинг игры пересчитывают ваши триггеры.
- **Администратор** — скрывает/публикует и удаляет любые рецензии, меняет роли пользователей.

## Защита от SQL-инъекций (пункт 10)

- Все запросы параметризованы (`@name`), строки запросов не склеиваются с вводом — см. `Data/Repository.cs`.
- Пароли не хранятся и не сравниваются в приложении: БД сама делает `crypt(@p, password_hash)` (bcrypt, pgcrypto).
- Поиск по названию экранирует `%`, `_`, `\`.
- Права проверяются и в приложении, и в SQL (`WHERE critic_id = @u OR @isAdmin`), а «только критик пишет рецензии» дополнительно
  гарантирует ваш триггер `trg_reviews_check_author`.
